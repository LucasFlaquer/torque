# CLAUDE.md

Guidance for AI coding agents working in this repository.

## What this is

Torque is a mechanic shop management app (study and portfolio project) built to practice fullstack development: data listing, pagination, caching and business rules under concurrency. Roles: `customer`, `attendant`, `mechanic`, `manager`.

Current status: initial Turborepo scaffold. Only the Next.js web app and the starter shared packages exist.

## Prerequisites

- Node.js `>=24` (developed with v24.15.0; enforced by `engines` in the root `package.json`)
- pnpm `11.25.0` (pinned through `packageManager` in the root `package.json`; use Corepack or a matching global install)

## Install

```sh
pnpm install
```

## Root scripts

Run these from the repository root. Each one (except `format`) runs a Turborepo task across all workspaces.

| Command            | What it does                                                                                |
| ------------------ | ------------------------------------------------------------------------------------------- |
| `pnpm dev`         | `turbo run dev`: starts every app in dev mode (web on http://localhost:3000)                |
| `pnpm build`       | `turbo run build`: production build of every app and package                                |
| `pnpm lint`        | `turbo run lint`: ESLint with `--max-warnings 0` in every workspace                         |
| `pnpm check-types` | `turbo run check-types`: type-check (`tsc --noEmit`; the web app runs `next typegen` first) |
| `pnpm format`      | Prettier `--write` over `**/*.{ts,tsx,md}`                                                  |

Run a task for a single workspace with a filter:

```sh
pnpm exec turbo run build --filter=web
pnpm --filter web dev
pnpm --filter @torque/ui lint
```

Before finishing a change, `pnpm build`, `pnpm lint` and `pnpm check-types` must pass.

## Workspace layout

```
apps/
  web/                    Next.js (App Router) web app, package name `web`
packages/
  ui/                     @torque/ui: shared React components (exports ./src/*.tsx)
  eslint-config/          @torque/eslint-config: ESLint flat configs (base, next-js, react-internal)
  typescript-config/      @torque/typescript-config: shared tsconfig bases (base, nextjs, react-library)
turbo.json                Turborepo task pipeline
pnpm-workspace.yaml       Workspace globs (apps/*, packages/*)
```

## Conventions

- English everywhere: code, comments, commit messages, docs, issues and PRs.
- TypeScript in strict mode (`strict` and `noUncheckedIndexedAccess` are on in `@torque/typescript-config/base.json`).
- Internal packages use the `@torque/*` scope and are referenced with `workspace:*`.
- Use `pnpm --filter <workspace>` to add dependencies or run scripts in one workspace; do not `cd` into packages and use another package manager.
- Run Turborepo tasks from the repository root so caching and task dependencies apply.
- Do not commit `node_modules`, `.turbo`, `.next` or `.env*` files (already in `.gitignore`).
- The root `AGENTS.md` holds a block managed by `turbo`, and `apps/web/AGENTS.md` / `apps/web/CLAUDE.md` are generated by `next dev`. They point to the version-matched docs bundled in `node_modules/turbo` and `node_modules/next`; read those docs before changing Turborepo or Next.js config. Keep these files committed and do not edit the managed blocks by hand.
